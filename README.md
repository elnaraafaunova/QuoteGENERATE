## Описание программы
Приложение "Генератор случайных цитат" — это настольная GUI-программа на Python (`customtkinter`), которая показывает случайные цитаты, хранит историю генерации и позволяет фильтровать её по автору и теме.

## Функционал
- Генерация случайной цитаты из встроенного набора.
- Отображение текущей цитаты: текст, автор, тема.
- История всех сгенерированных цитат с временем генерации.
- Фильтрация истории по автору и теме (можно комбинировать).
- Сохранение истории в `data/data.json`.
- Загрузка истории при запуске программы.
- Обработка отсутствующего и поврежденного JSON-файла.
- Добавление новых цитат с валидацией:
  - `Цитата не может быть пустой`
  - `Автор не может быть пустым`
- Очистка истории.
- Отображение количества сгенерированных цитат.

## Как запустить
1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустить приложение:
   ```bash
   python main.py
   ```
3. Запустить тесты:
   ```bash
   pytest
   ```

## Примеры использования
1. Нажмите кнопку **"Сгенерировать цитату"** — отобразится новая цитата, а в истории появится запись с текущим временем.
2. Введите значение в **"Фильтр по автору"** и/или **"Фильтр по теме"**, затем нажмите **"Применить фильтр"**.
3. Для добавления своей цитаты заполните поля **"Новая цитата"**, **"Автор"**, **"Тема"** и нажмите **"Добавить цитату"**.
4. Для полного удаления истории нажмите **"Очистить историю"**.
